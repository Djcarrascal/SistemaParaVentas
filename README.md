# SistemaParaVentas
Creé un sistema que permite registrar datos de un cliente, productos, valores, cálculos con descuentos y que genere una tirilla de la venta. Solo funciona en consola.

Se tuvo en cuenta que si el cliente tiene membresia VIP obtendra un descuento del 10% en el valor total de la compra.

Lo hice utilizando el leguaje básico de Python con:
- Entradas y salidas de datos 
- Variables
- Funciones
- Bucle
- Condicionales
